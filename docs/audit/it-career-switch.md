# Learning ML Atlas after five years in IT

**Start with the taxi data.** If you have investigated a malformed record, a failed job or an unexpected change in a dashboard, the first Pandas lessons give you a familiar problem. The bigger adjustment comes when you fit a model. A program can run correctly, pass its tests and still make poor predictions on new data. Learn to measure that before studying more architectures. [First taxi lesson](../../react-app/src/content/pandas-eda/eda-m1.mdx) · [Validation sets](../../react-app/src/content/model-eval/me-m2.mdx)

This assessment assumes experience troubleshooting software or working with data, basic arithmetic and little AI vocabulary. Python experience varies across IT roles. The entry check is whether you can run a notebook cell, call a method and select a column from a table. If that is unfamiliar, use the loading cell in the first taxi lesson, print one fare column, restart the notebook and reproduce the result. Python syntax and notebook state are the first skills to practise.

## Two routes through the material

| Destination | First pass through the existing lessons | Check that you can use it |
|---|---|---|
| Data scientist | Inspect and clean the taxi table. Study averages and variation, fit a linear model, then learn validation splits and decision trees. Use the regression lab to compare predictions on held-out rows. Add hypothesis testing for experiments or time series for forecasts. | Given a housing table, write down when the prediction is made, which fields are available then and what the target is. Compare the model with a baseline that always predicts the mean training price. Report average absolute error in currency units and inspect the largest miss. [Regression lab](../../Regression/notebooks/01_linear_regression_lab.ipynb) |
| AI or ML engineer | Start with the same data, model and validation basics. Follow one neural-network weight update. For vision, continue with convolutions and transfer learning. For language, follow recurrent state, attention and transformers. Finish with the MLOps capstone and the risk lessons relevant to the application. | For a language project, use a short support ticket and three candidate tickets. Calculate which candidate is closest using sentence embeddings, inspect one poor match and explain how you would evaluate retrieval on labeled pairs before release. [Sentence embeddings](../../react-app/src/content/transformers/trf-m13.mdx) · [Production capstone](../../react-app/src/content/mlops/mlops-m7.mdx) |

Treat the generative model tracks as a specialization. One way to decide which to study is to ask what produces the training signal. A VAE learns to reconstruct an input from a sampled code while regularizing its distribution. A GAN's generator receives feedback from a discriminator. In the diffusion lab, the learner adds known noise to an image and uses that noise as a prediction target. Being able to describe those three experiments is a useful first milestone. [Generative model comparison](../revision/vision-and-genai.md#4-generative-model-families-and-vision-transformers)

## Track-by-track assessment

The level describes the effort to follow the **whole track**. **Start here** means the opening exercises are usable with the entry skills above. **After a primer** means one or two named concepts unlock most of the material. **Specialist** means later lessons rely on several earlier tracks or on implementing a model. A learner can use an introductory lesson from any level.

| Subtopic | Level | What helps and where to slow down |

| Mathematics for Machine Learning | After a primer | Arrows and dot products give a concrete entry. The PCA lesson uses a covariance matrix in module 4, while covariance is taught in module 7. ### Advanced Deep Learning

The first subtopic supplies the neural-network foundation. From there, use the prerequisites below to choose a path into images, sequences or generation.

| Subtopic | Level | What helps and where to slow down |
|---|---|---|
| Foundations of Deep Learning | After a primer | A weighted sum and a prediction error unlock the perceptron. The single-weight visual in backpropagation connects derivatives to an actual update. Trace it once before following the full matrix derivation or comparing optimizers. [One weight update](../../react-app/src/content/deep-learning/dl-m6.mdx) |
| Convolutional Neural Networks (CNNs) | After a primer | Slide one filter over a grid and calculate one output by hand. Then add channels and batches. If parameter counts become confusing, write the shape of the input, kernel and output before looking at the formula. [Convolution operations](../../react-app/src/content/cnn/cnn-m2.mdx) |
| Computer Vision | Specialist | Pixel values, crops and bounding boxes are approachable. Detection evaluation adds several decisions to a single calculation. Draw two overlapping boxes, decide which prediction matches the label and then count duplicate detections. [Detection evaluation](../../react-app/src/content/computer-vision/cv-m10.mdx) |
| Transfer Learning, Embeddings and U-Net | Specialist | Replacing an image classifier's final layer gives an early practical result. The second half changes the output to a label per pixel. Sketch the input image, predicted mask and reference mask before tracing the U-Net skip connections. [Fine-tuning demo](../../react-app/src/content/transfer-learning/tl-m3.mdx) · [U-Net](../../react-app/src/content/transfer-learning/tl-m10.mdx) |
| Recurrent Neural Networks | After a primer | Think of the hidden state as the value carried through a loop. Trace three events with the same weights before following gradients back through time. The gate equations are easier once you can say what information the example needs to remember. [One recurrent cell](../../react-app/src/content/rnn/rnn-m6.mdx) |
| Attention and Encoder-Decoder Models | Specialist | Familiarity with a sequence and its hidden states matters here. For one output word, compute the context from two values, 2 and 8, with weights 0.25 and 0.75. The result is 6.5. Now the alignment diagram has a quantity you can check. [Attention step by step](../../react-app/src/content/attention-seq2seq/aed-m7.mdx) |
| Transformers | Specialist | The same sentence runs through several lessons, so a token can be followed across diagrams. Trace one row of attention and which positions its mask permits. Then compare encoder-only, decoder-only and encoder–decoder models before opening the fine-tuning code. [One attention row](../../react-app/src/content/transformers/trf-m4.mdx) · [Architecture variants](../../react-app/src/content/transformers/trf-m10.mdx) |
| Variational Autoencoders (VAEs) | Specialist | Compression provides an entry. The hard step is reasoning about a distribution of codes for one input. Sample one code, decode it and name the reconstruction and regularization terms. Module 4 now uses the numbers 2, 3 and 5 to show how the lower bound can improve even when the exact value stays fixed. [ELBO lesson](../../react-app/src/content/vae/vae-m4.mdx) |
| Generative Adversarial Networks (GANs) | Specialist | The two networks have understandable roles. During a training step, name which network receives an update and what signal it receives. The Wasserstein and gradient-penalty lesson adds a new distance and a constraint, best revisited after seeing mode collapse. [Mode collapse](../../react-app/src/content/gan/gan-m4.mdx) · [Gradient penalty](../../react-app/src/content/gan/gan-m6.mdx) |
| Diffusion Models | Specialist | Adding visible noise gives an intuitive start. The jump is from one noisy sample to a probability distribution across many timesteps. Draw the clean input, sampled noise and noisy input for one training example. Then identify the target the denoiser sees in the PyTorch demo. [Forward noising](../../react-app/src/content/diffusion/diffusion-m2.mdx) · [Training demo](../../react-app/src/content/diffusion/diffusion-m10.mdx) |

## Labs and revision material

- **23 notebooks.** Ten Spark notebooks pair a single operation with practice problems. The two regression labs start with implementations from scratch, which makes their first cells a steeper entry than the price example. Of the eleven specialist notebooks, the forecasting and recommender labs carry one dataset through several decisions. The VAE, GAN and diffusion labs include dataset downloads and training, while the GenAI risks lab uses the Python standard library. Use a small shape, score or prediction that you can verify before interpreting a full training run. [Spark labs](../../etl-pyspark/notebooks) · [Regression labs](../../Regression/notebooks) · [Specialist labs](../../notebook)
- **Revision guides.** The bookshop questions give the applied guide a common setting. The vision and GenAI guide uses captioning and image generation to connect several architectures. Both work well for recall after a first lesson. The 16 scenario questions test whether you can distinguish nearby choices. Question 3 assumes support-vector margins and hinge loss, which have no dedicated track here. Use the signed-margin formula in its answer key as a separate worked exercise. [Applied ML](../revision/applied-ml.md) · [Vision and GenAI](../revision/vision-and-genai.md) · [Scenario practice](../revision/scenario-practice.md)
- **Standalone transformer material reviewed locally.** The comparison in `transformer_types.html` has diagrams and self-tests for revisiting the three architectures. The notes in `transformer.md` move from a recurrent encoder to a sentiment classification head described as a decoder, and reference a missing `image_ed.png`. That transition can make a newcomer confuse a classifier with a sequence-generating decoder. Use the portal's two-RNN translation example for a first reading. [Translation example](../../react-app/src/content/attention-seq2seq/aed-m2.mdx)

## Highest-value teaching improvements

1. **Give beginners a Python and notebook starting exercise.** The taxi lesson names lists, dictionaries and method calls as prerequisites. A small exercise that loads the CSV, selects a column and recovers from restarting the kernel would reveal a setup or Python gap before the learner tries to reason about missing data.
2. **Put one checkable calculation before each dense derivation.** The price calculation in regression, the covariance link in PCA and the numerical counterexample in the VAE lesson address three such jumps. The hypothesis-testing track is a candidate for the same treatment. Follow one rollout experiment through false alarms and misses before introducing all the error symbols together.
3. **Test independent decisions earlier.** The guided labs and quizzes supply many intermediate choices. A small independent assignment after model validation could ask for a baseline, split, metric and one explained error on the same data. A learner could bring that notebook to a project discussion and justify each choice.
