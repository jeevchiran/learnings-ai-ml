## Where the Numbers Break

The Naive Bayes score is a product of many sub-1 probabilities:

$$\text{score}(y) = P(y) \prod_{i=1}^{n} P(x_i \mid y)$$

Each factor shrinks the running product. With hundreds or thousands of features — a realistic vocabulary — it shrinks *exponentially*, roughly $0.2^n$.

```python
import numpy as np

rng = np.random.default_rng(0)
likelihoods = rng.uniform(0.05, 0.3, size=2000)   # 2000 typical NB likelihoods
print(np.prod(likelihoods))
```

```
0.0
```

Not "very small" — exactly `0.0`. Float64 bottoms out near $10^{-308}$; this product needs ~$10^{-1500}$. Once it underflows, *every* class scores zero, the arg-max degenerates to `0.0 == 0.0`, and real information is destroyed by the representation, not the model.

<ConceptBox title="Not a corner case">
Any vocabulary in the thousands underflows on a normal document. Every production implementation — scikit-learn included — works in log-space for this reason. It's a baseline requirement, not an optimization.
</ConceptBox>

## The Log-Space Trick

One identity: logs turn products into sums.

$$\log\left(P(y)\prod_{i=1}^n P(x_i\mid y)\right) = \log P(y) + \sum_{i=1}^n \log P(x_i \mid y)$$

<DerivationSteps>
<DerivationStep number={1} title="Take the log">
$$\log\,\text{score}(y) = \log\!\left(P(y)\prod_i P(x_i\mid y)\right)$$
</DerivationStep>
<DerivationStep number={2} title="log(ab) = log a + log b">
$$\log\,\text{score}(y) = \log P(y) + \sum_{i=1}^{n}\log P(x_i\mid y)$$
A product of $n{+}1$ tiny numbers becomes a sum of moderate negatives — no underflow.
</DerivationStep>
<DerivationStep number={3} title="log is monotonic, so arg-max is preserved">
$$\hat{y} = \arg\max_y \; \text{score}(y) = \arg\max_y \; \log\,\text{score}(y)$$
The winning class is identical; only the numerical path changed.
</DerivationStep>
</DerivationSteps>

```python
log_score = np.log(0.6) + np.sum(np.log(rng.uniform(0.05, 0.3, size=2000)))
print(log_score)     # -3705.74...
```

A large negative but perfectly finite float — the same information the raw product would carry with infinite precision.

## Recovering Probabilities: `logsumexp`

Classification needs only the arg-max, so log-scores suffice to predict. Reporting a normalized posterior means dividing by $\sum_k \text{score}(y_k)$ — but exponentiating first reintroduces underflow. The **log-sum-exp trick** factors out the largest log-score before exponentiating:

$$\log\sum_k e^{a_k} = a_{\max} + \log\sum_k e^{a_k - a_{\max}}$$

```python
from scipy.special import logsumexp

log_score_a, log_score_b = -359.36, -363.16
log_norm = logsumexp([log_score_a, log_score_b])
posterior_a = np.exp(log_score_a - log_norm)
posterior_b = np.exp(log_score_b - log_norm)
print(posterior_a, posterior_b, posterior_a + posterior_b)   # 0.9781 0.0219 1.0
```

Every term is shifted by $a_{\max}$ before exponentiating, so the largest exponent is $e^0 = 1$ — nothing overflows or underflows. This is exactly how scikit-learn's `predict_proba` recovers 0–1 probabilities from internal log-probabilities.

<ConceptBox title="What changes in code">
Every `P(x_i|y)` → `log P(x_i|y)`, every `*` → `+`, prior multiplication → `+ log(prior)`, and `logsumexp` only if you need normalized probabilities. `predict` never exponentiates — arg-max is invariant under a monotone transform.
</ConceptBox>

## Practice

#### Problem 1: Underflow Threshold
With each likelihood ≈ 0.2, roughly how many features underflow below $10^{-308}$?

**Solution:** Solve $0.2^n < 10^{-308}$: $n > 308/0.699 \approx 440$. About 440 features — well inside a normal vocabulary (10,000+ words), confirming log-space is a baseline requirement, not an edge case.

#### Problem 2: Why Not Rescale?
A student proposes multiplying every likelihood by 10, then dividing the result by $10^n$. Does it work?

**Solution:** No — it turns underflow into *overflow*. The intermediate product grows as $(10 \times 0.2)^n = 2^n$, hitting `inf` for moderate $n$, and `inf / 10**n` is unrecoverable. A constant rescale can't fix exponential blow-up; only log-space, where multiply becomes add, avoids exponential growth or decay entirely.
