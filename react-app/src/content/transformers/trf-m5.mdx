# Module 5: Value Vectors and Word Context Through Attention

## A third projection: Value

<PredictReveal
  prompt="Query and Key decide HOW MUCH attention creature pays to fluffy. What decides WHAT actually gets absorbed into creature's embedding once that weight is set?"
  options={["The Key vector of fluffy, reused", "A third, separate projection: the Value vector"]}
  correct={1}
>

$$v_j = W_V\, e_j$$

Query and Key exist purely to compute a *weight* — a number saying how relevant word $j$ is to word $i$. They never touch the actual content that gets moved. That's the **Value** vector's job: a third projection of the same embedding, representing what word $j$ actually contributes to any word that attends to it.

The final update to word $i$'s embedding is a weighted sum of every other word's Value vector, using the attention weights from Module 4:

$$\Delta e_i = \sum_j \alpha_{ij}\, v_j$$

Continuing Module 4's hand example, with $\alpha = [0.433,\ 0.391,\ 0.176]$ over fluffy, blue and creature, and the toy Value vectors $v_{\text{fluffy}} = [0.9,\ 0.1]$, $v_{\text{blue}} = [0.7,\ 0.15]$ and $v_{\text{creature}} = [0.15,\ 0.9]$:

$$\Delta e_{\text{creature}} = 0.433\,[0.9,\ 0.1] + 0.391\,[0.7,\ 0.15] + 0.176\,[0.15,\ 0.9] = [0.690,\ 0.260]$$

Axis 0 is the toy texture-and-colour axis, so the update is mostly *descriptive* content — exactly what a noun collecting its adjectives should absorb.

</PredictReveal>

## The update, concretely

<PredictReveal
  prompt='Before attention, "creature" is a generic embedding. After attention pulls in "fluffy" and "blue" via their Value vectors, is the updated embedding a completely new vector, or the original plus an addition?'
  options={["A completely new, unrelated vector", "The original embedding plus Δe — an addition, not a replacement"]}
  correct={1}
>

<ValueUpdateWidget />

$$e_i' = e_i + \Delta e_i$$

For the hand example, $e_{\text{creature}} = [0.2,\ 0.5]$, so $e' = [0.2 + 0.690,\ 0.5 + 0.260] = [0.890,\ 0.760]$. Select creature in the widget above; its numbers differ slightly only because the widget includes all eight tokens and a small recency bonus.

Attention never throws away the original embedding — it *adds* a context-dependent correction to it. "Creature" still means creature; it now also means *this specific* creature, fluffy and blue. Run this for every word in the sentence and the whole sequence goes from a bag of dictionary definitions to a set of vectors that actually encode this sentence, this meaning, this context.

</PredictReveal>

<ConceptBox title="TL;DR">
- A third projection, $v_j = W_V e_j$, produces the **Value** vector — what a position actually contributes, separate from how much attention it receives.
- The attention output is $\Delta e_i = \sum_j \alpha_{ij} v_j$ — a weighted sum of Value vectors, using the weights Query/Key computed.
- The update is additive: $e_i' = e_i + \Delta e_i$ — context refines the embedding, it doesn't replace it.
- This is the concrete fix for the context-independence problem that opened the previous track: the same word gets a genuinely different final embedding depending on what surrounds it, computed per sentence rather than looked up from a fixed table.
</ConceptBox>
