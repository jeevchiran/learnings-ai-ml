<ConceptBox title="TL;DR">
- Impurity $I(t)$ = 0 when a node is pure, maximal when classes are evenly mixed. **Gain** = parent impurity − weighted child impurity; pick the split that maximises it.
- **Gini** = chance two random draws differ in class; binary max **0.5**. **Entropy** = bits to encode a label; binary max **1**.
- **Misclassification rate is not used for splitting** — it's piecewise linear, so it can report zero gain for a split that genuinely improves separation.
- Gini and entropy nearly always pick the same split. Gini is the default because it avoids a logarithm.
- Weighting children by size is essential — otherwise a pure 1-sample child would look like a triumph.
</ConceptBox>

## Why a Splitting Criterion?

A tree recursively partitions data; at each node it must pick *which feature and threshold* give the best split. Without a measure of "good," candidate splits can't be compared. 10 patients (6 positive, 4 negative), two candidate splits:

| Split | Left | Right | Quality |
|---|---|---|---|
| **A** | 5+, 1− | 1+, 3− | both children fairly homogeneous |
| **B** | 3+, 3− | 3+, 1− | left is a coin flip — useless |

A is clearly better — *purer* children. But intuition isn't an algorithm; we need a number.

<Bridge>
We want a scalar $I(t)$ that is 0 at a pure node and maximal when classes are evenly mixed. The **gain** of a split is $I(\text{parent}) - $ weighted child impurity; pick the split maximizing it. Three standard $I$: Gini impurity, entropy, misclassification rate.
</Bridge>

## Gini Impurity

Pick two samples at random (with replacement) from a node — the probability they're *different* classes is the Gini impurity:

$$G(t) = \sum_{k=1}^{K} p_k(1 - p_k) = 1 - \sum_{k=1}^{K} p_k^2$$

(Equivalent since $\sum_k p_k = 1$.)

<ConceptBox title="Properties">
- $G = 0$ when pure (one $p_k = 1$).
- $G = 1 - 1/K$ maximum, when all K classes equal.
- Binary: $G = 2p(1-p)$, max **0.5** at $p = 0.5$.
</ConceptBox>

**Example** (6+, 4−): $p_+^2 + p_-^2 = 0.36 + 0.16 = 0.52$, so $G = 1 - 0.52 = 0.48$ — near the 0.5 max, confirming a balanced node.

## Shannon Entropy

Average bits to encode a random sample's label — 0 if pure, maximal if evenly mixed:

$$H(t) = -\sum_{k=1}^{K} p_k \log_2 p_k \qquad (0 \log_2 0 = 0)$$

<ConceptBox title="Properties">
- $H = 0$ pure; $H = \log_2 K$ maximum.
- Binary max **1 bit** at $p = 0.5$.
- More sensitive than Gini near pure nodes, so it can prefer splits isolating small pure subsets.
</ConceptBox>

**Example** (6+, 4−): $-(0.6\log_2 0.6 + 0.4\log_2 0.4) = -(-0.442 - 0.529) = 0.971$ bits — near the 1-bit max.

## Misclassification Rate

Assign the node's majority class to all; the misclassified fraction:

$$E(t) = 1 - \max_k p_k$$

For 6/4: $E = 0.4$. **Why it's not used for splitting:** parent (6+, 4−), $E = 0.4$.
- **Split X:** (4+,4−) and (2+,0−) → weighted $E = 0.8(0.5) + 0.2(0) = 0.4$, gain **0**.
- **Split Y:** (4+,1−) and (2+,3−) → weighted $E = 0.5(0.2) + 0.5(0.4) = 0.30$, gain **0.10**.

Y is clearly better, yet $E$ reports zero gain for X because the majority class didn't flip. Gini and entropy both reward Y — this insensitivity makes $E$ a poor split criterion.

## Information Gain and Gini Gain

For a split sending $|t_L|$ left and $|t_R|$ right:

$$\text{IG} = H(t) - \frac{|t_L|}{|t|} H(t_L) - \frac{|t_R|}{|t|} H(t_R), \qquad \text{GG} = G(t) - \frac{|t_L|}{|t|} G(t_L) - \frac{|t_R|}{|t|} G(t_R)$$

Choose the feature/threshold that **maximizes** the gain.

**Worked IG.** Parent (6+, 4−); split → left (5+,1−), right (1+,3−).

<DerivationSteps>
<DerivationStep number={1} title="Parent">
$H = 0.971$ bits.
</DerivationStep>
<DerivationStep number={2} title="Children">
$H_L = -\tfrac{5}{6}\log_2\tfrac{5}{6} - \tfrac{1}{6}\log_2\tfrac{1}{6} = 0.650$; $H_R = -\tfrac{1}{4}\log_2\tfrac{1}{4} - \tfrac{3}{4}\log_2\tfrac{3}{4} = 0.811$.
</DerivationStep>
<DerivationStep number={3} title="Weighted + gain">
$\tfrac{6}{10}(0.650) + \tfrac{4}{10}(0.811) = 0.714$; $\text{IG} = 0.971 - 0.714 = \mathbf{0.257}$ bits.
</DerivationStep>
</DerivationSteps>

## The CART Algorithm

CART (Breiman et al. 1984) finds each split by exhaustive search — try every feature × threshold, compute the gain, keep the best, recurse:

```
BuildTree(data, depth, maxDepth, minSamples):
  if depth == maxDepth or |data| < minSamples or all labels same:
    return Leaf(majority_class(data))
  bestGain, bestFeature, bestThreshold = -INF, None, None
  for each feature j:
    for each unique value t in data[j]:
      left  = data where x_j <= t
      right = data where x_j >  t
      gain  = GiniGain(data, left, right)
      if gain > bestGain:
        bestGain, bestFeature, bestThreshold = gain, j, t
  return Node(bestFeature, bestThreshold,
              left  = BuildTree(leftData,  depth+1, ...),
              right = BuildTree(rightData, depth+1, ...))
```

**Stopping criteria:** max depth (`max_depth`); too few samples (`min_samples_split`/`min_samples_leaf`); gain below `min_impurity_decrease`; or a pure node.

**Complexity:** naive per-node $O(n^2 p)$; over depth $d$, $O(n^2 p d)$. scikit-learn pre-sorts each feature once, cutting per-node cost to $O(n \log n \cdot p)$.

## Practice

**Problem 1 — Impurity by hand.** Node: 5 class A, 3 class B ($p_A = 0.625$, $p_B = 0.375$).
- Gini: $1 - (25/64 + 9/64) = 30/64 \approx 0.469$.
- Entropy: $-(0.625\log_2 0.625 + 0.375\log_2 0.375) = 0.954$ bits.
- Misclassification: $1 - 5/8 = 0.375$.

**Problem 2 — Gini Gain, two splits.** Parent (6+, 4−), $G = 0.48$.
- **A:** (4+,0−) pure $G_L=0$; (2+,4−) $G_R = 1 - (4/36+16/36) \approx 0.444$. $\text{GG}_A = 0.48 - 0.6(0.444) = \mathbf{0.213}$.
- **B:** (3+,1−) $G_L = 0.375$; (3+,3−) $G_R = 0.5$. $\text{GG}_B = 0.48 - 0.4(0.375) - 0.6(0.5) = \mathbf{0.030}$.

A wins — it isolates all 4 positives in a pure child.

**Problem 3 — Gini max and bound.** (1) $\frac{d}{dp}[2p(1-p)] = 2 - 4p = 0 \Rightarrow p = 0.5$; second derivative $-4 < 0$ → max $G = 0.5$. (2) With $E = \min(p, 1-p)$, $G = 2p(1-p) \leq 2\min(p, 1-p) = 2E$.
