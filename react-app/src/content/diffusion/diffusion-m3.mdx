# Module 3: The Reverse (Denoising) Process

<Bridge>

## Why the reverse step is tractable at all

<PredictReveal
  prompt="Reversing an arbitrary noising process exactly would require inverting q(x_0 | x_t) — a distribution over every possible clean image that could have produced this particular noisy one. Why is a single reverse step still tractable to approximate, when the forward process adds noise in small steps?"
  options={["It isn't tractable — reverse diffusion is only possible with an exact, closed-form inverse", "For a small enough forward step β_t, the true reverse step q(x_{t-1}|x_t) is itself approximately Gaussian, so a Gaussian is a good model for it"]}
  correct={1}
>

<ReverseDenoisingWidget />

This is the key theoretical fact diffusion models depend on: for a sufficiently small forward step, the true reverse distribution $q(x_{t-1} | x_t)$ is well-approximated by a Gaussian. That is why the model doesn't need to represent the reverse process exactly, or handle the full, complicated $q(x_0|x_t)$ — it only needs to approximate a small local reverse step, and a Gaussian is a good local approximation exactly when the forward step it's undoing was small.

</PredictReveal>

## What the reverse model actually predicts

<PredictReveal
  prompt="If p_θ(x_{t-1} | x_t) is modeled as a Gaussian with a learned mean and (often) a fixed variance, what does 'training the reverse process' mean in practice?"
  options={["Training a classifier to distinguish real from generated images at each step", "Training a network to predict the mean of that Gaussian (or equivalently, the noise that was added) at each timestep t"]}
  correct={1}
>

$p_\theta(x_{t-1} \mid x_t) = \mathcal{N}\big(x_{t-1};\ \mu_\theta(x_t, t),\ \Sigma_t\big)$ — a single neural network $\mu_\theta$, shared across all timesteps and conditioned on $t$, predicts the mean of the reverse step. Module 4 shows that predicting this mean turns out to be mathematically equivalent to predicting the noise $\epsilon$ that the forward process added — which is the form the actual training loss takes.

</PredictReveal>

<Recall items={[
  { q: "What does the reverse process's neural network actually output, and how many networks are needed across all T timesteps?", a: "A single network, conditioned on the timestep t, predicts the mean of the Gaussian reverse step (equivalently, the noise added at that step). One shared network handles every timestep — there is no separate network per t." },
]} />

---

<ConceptBox title="TL;DR">
- Reversing an arbitrary noising process exactly is intractable, but for a **small** forward step, the true reverse step $q(x_{t-1}|x_t)$ is itself approximately Gaussian — which is exactly what makes it learnable.
- $p_\theta(x_{t-1}|x_t)$ is modeled as a Gaussian with a **learned mean** $\mu_\theta(x_t, t)$, produced by a single network shared across every timestep.
- Training this network turns out to be equivalent to predicting the noise added at each step — the subject of Module 4.
</ConceptBox>
