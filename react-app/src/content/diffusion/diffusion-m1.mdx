## No game, no single fast pass

<PredictReveal
  prompt="A GAN trains two competing networks against a shared adversarial objective. A diffusion model has no discriminator and no minimax game at all. What does it train instead?"
  options={["A single network trained with an ordinary regression loss to reverse a fixed, known corruption process", "Two generators translating between domains, the same as CycleGAN"]}
  correct={0}
>

A diffusion model defines a fixed, mathematically known process that gradually destroys an image into pure noise — no learning involved in that direction at all. It then trains a single network to reverse one small step of that destruction at a time, using an ordinary supervised regression loss. There is no adversary to fool and no saddle point to search for, which sidesteps the entire training-instability story from the GAN track: no mode collapse, no vanishing-gradient race between two networks, no Nash equilibrium to hope for.

</PredictReveal>

## The trade: one fast pass for many slow ones

<PredictReveal
  prompt="A GAN's generator turns noise into an image in a single forward pass. If a diffusion model instead reverses corruption one small step at a time, how many network evaluations does producing one image typically take?"
  options={["Exactly one, the same as a GAN", "Many — often hundreds to thousands of sequential network evaluations"]}
  correct={1}
>

Because the reverse process only reliably undoes *small* corruption steps, generating a sample means applying the learned denoising step repeatedly, in sequence — each step depends on the output of the previous one, so they cannot be parallelized away. This is the central cost of diffusion models, and it is a direct, mechanical consequence of the same design choice that removes the adversarial instability: reversing a large corruption in one shot is hard to learn reliably, but reversing many tiny corruptions, one at a time, is comparatively easy to get right.

</PredictReveal>

<ConceptBox title="TL;DR">
- A diffusion model has **no adversarial game**: a fixed, known process gradually destroys data into noise, and a single network is trained with an ordinary regression loss to reverse one small step of that destruction.
- This sidesteps GAN-style training instability entirely — no discriminator, no saddle point, no mode collapse.
- The cost is sampling speed: generating one sample requires many **sequential** network evaluations (undoing corruption one small step at a time), unlike a GAN's single forward pass.
</ConceptBox>
