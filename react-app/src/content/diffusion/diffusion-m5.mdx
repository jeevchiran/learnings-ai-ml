## Reusing U-Net, for a different task

Both tasks share the same underlying requirement: take an image, extract features at multiple scales, and produce a full-resolution output the same size as the input. U-Net's downsampling path builds a multi-scale feature hierarchy, its upsampling path (Transfer Learning track's transposed convolutions) reconstructs full resolution, and its skip connections carry fine spatial detail across the bottleneck — all useful regardless of whether the final output is a segmentation mask or a noise estimate.

## One network, every noise level

<PredictReveal
  prompt="The same U-Net must denoise x_t whether t = 1 (barely noisy) or t = 900 (almost pure noise) — very different tasks in practice. How does a single set of weights handle both?"
  options={["It doesn't — a separate network is trained for each timestep", "The timestep t is embedded into a vector (typically via sinusoidal position encoding, the same idea from the Transformers track) and injected into every block of the network"]}
  correct={1}
>

$t$ is converted into a vector using **sinusoidal timestep embeddings** — the same positional-encoding idea from the Transformers track, repurposed here to encode a scalar timestep instead of a sequence position. That embedding is added into the feature maps at every resolution level of the U-Net, usually after a small MLP. This lets one shared network condition its behavior on how much noise it should expect to see, rather than needing $T$ separate networks.

</PredictReveal>

<ConceptBox title="TL;DR">
- The diffusion denoiser reuses **U-Net** (Transfer Learning track): downsampling for multi-scale features, upsampling for full resolution, skip connections for detail — the same shape a dense image-to-image task needs, regardless of what the output represents.
- The new ingredient is **timestep conditioning**: a sinusoidal embedding of $t$ (the same idea as Transformer positional encodings) is injected into every block.
- This lets a **single shared network** handle every noise level from $t=1$ to $t=T$, instead of requiring $T$ separately trained networks.
</ConceptBox>
