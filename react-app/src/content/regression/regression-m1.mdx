## What Is Linear Regression?

It models a continuous response $y$ as a linear function of predictors $x_1,\ldots,x_p$:

$$y = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p + \varepsilon$$

$\beta_0$ = intercept, $\beta_j$ = coefficients, $\varepsilon$ = irreducible error. Geometrically: a line (one predictor), a plane (two), a hyperplane in general — find the one best fitting the data.

**"Best fit"** = minimizing the sum of squared residuals (OLS):

$$\text{SSR} = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 = \sum_{i=1}^{n}\Big(y_i - \beta_0 - \sum_j \beta_j x_{ij}\Big)^2$$

## Assumptions

OLS has its good properties (unbiasedness, efficiency) only when these hold:

1. **Linearity** — the true relationship is linear; a curved one gets systematically misfit.
2. **Independence** — errors are uncorrelated (violated by autocorrelation in time series).
3. **Homoscedasticity** — constant error variance $\text{Var}(\varepsilon_i) = \sigma^2$; otherwise standard errors are unreliable.
4. **Normality of errors** — $\varepsilon_i \sim \mathcal{N}(0,\sigma^2)$; needed for inference, not point estimates.
5. **No perfect multicollinearity** — else $X^TX$ is singular and OLS has no solution; near-collinearity inflates coefficient variance.
6. **Exogeneity** — $E[\varepsilon \mid X] = 0$; violated by omitting relevant variables or measurement error.

## Interpreting Coefficients

Each $\beta_j$ is the expected change in $y$ per one-unit increase in $x_j$, *holding others constant*:

$$\beta_j = \frac{\partial\, E[y \mid \mathbf{x}]}{\partial x_j}$$

**Unstandardized** coefficients are in original units (150 for SqFt = \$150 per sq ft). **Standardized** ones (variables scaled to mean 0, SD 1) let you compare importance across scales: $\beta_j^{\text{std}} = \beta_j \cdot s_{x_j}/s_y$.

**House-price example:** $\text{Price} = -50{,}000 + 150\,\text{SqFt} + 20{,}000\,\text{Bedrooms} - 5{,}000\,\text{DistanceKm}$.

| Coefficient | Value | Meaning (all else equal) |
|---|---|---|
| $\beta_1$ SqFt | +\$150 | per additional sq ft |
| $\beta_2$ Bedrooms | +\$20,000 | per additional bedroom |
| $\beta_3$ Distance | −\$5,000 | per km from center |

## Evaluating Performance

**R²** — proportion of variance explained:

$$R^2 = 1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$$

**Adjusted R²** penalizes complexity (plain R² only rises as predictors are added):

$$R^2_{\text{adj}} = 1 - \frac{(1 - R^2)(n - 1)}{n - p - 1}$$

**MSE / RMSE** — RMSE is in the units of $y$: $\text{RMSE} = \sqrt{\frac{1}{n}\sum(y_i - \hat{y}_i)^2}$. RMSE \$15,000 = predictions off by ~\$15K.

## Residual Diagnostics

Residuals $e_i = y_i - \hat{y}_i$ are the primary tool for checking assumptions. Four plots:

- **Residuals vs Fitted** — should be a random cloud at zero; curve = nonlinearity, funnel = heteroscedasticity.
- **Normal Q-Q** — points on the diagonal if errors are normal; tail deviations = heavy tails/skew.
- **Scale-Location** — $\sqrt{|e_i^*|}$ vs fitted; flat = constant variance, upward = heteroscedasticity.
- **Residuals vs Leverage** — high leverage *and* large residual (outside Cook's contours) = influential point.

$$e_i^* = \frac{e_i}{\hat{\sigma}\sqrt{1 - h_{ii}}}, \qquad D_i = \frac{e_i^{*2}}{p+1}\cdot\frac{h_{ii}}{1 - h_{ii}}$$

$h_{ii}$ = leverage (hat-matrix diagonal). Cook's distance $> 1$ flags points to investigate.

## Practice

**Problem 1 — Funnel residuals.** Rent-vs-sqft residuals fan out for high rents.

**Solution:** **Homoscedasticity** violated (variance grows with fitted value). Standard errors/CIs are invalid — too narrow at high values. Fixes: weighted least squares (weights ∝ 1/variance), a variance-stabilizing transform (log rent), or heteroscedasticity-consistent (HC1/HC3) standard errors.

**Problem 2 — Cook's distance.** 200 obs; $D_i$ = 0.003, 0.45, 1.8 (the last is a CEO, salary \$2.5M vs \$85K mean).

**Solution:** Threshold $4/n = 0.02$ (or stricter $D_i > 1$). $D_i = 0.45$ warrants inspection; the CEO ($1.8$) is highly influential. **Don't remove** if the CEO is a legitimate population member; **remove/model separately** if predicting *typical* salaries, or use robust regression (Huber). Quantify without removing via **DFBETAS** — the standardized coefficient change when point $i$ is deleted.

**Problem 3 — Misspecification.** Residuals-vs-fitted looks fine, but residuals-vs-age is U-shaped; Q-Q normal; $R^2 = 0.74$.

**Solution:** (1) The fitted plot averages over age's nonlinearity because size/distance dominate $\hat y$; the per-predictor plot isolates it — always plot residuals against each predictor. (2) Add a quadratic: $\text{Price} = \beta_0 + \beta_1\text{SqFt} + \beta_2\text{Age} + \beta_3\text{Age}^2 + \beta_4\text{Distance} + \varepsilon$. (3) Partial F-test ($\text{RSS}_r=1300$, $\text{RSS}_f=900$, $n=500$, $q=1$): $F = \frac{(1300-900)/1}{900/495} = \frac{400}{1.818} = 220 \gg F_{1,495}^{0.05} \approx 3.86$ → highly significant.

## Limitations

- **Outlier-sensitive** — OLS squares errors, so one extreme point shifts the line.
- **Linearity** — a nonlinear truth underfits; needs polynomial features or another model.
- **Multicollinearity** — correlated predictors make coefficients unstable (predictions can stay fine).
- **Can't classify** — predicts $(-\infty, \infty)$, giving "probabilities" outside [0,1] for binary outcomes → logistic regression (Module 3).
