## Expectation — The Probability-Weighted Average

$$E[X] = \sum_x x\,P(X{=}x) \qquad\text{(discrete)} \qquad\qquad E[X] = \int x\,f(x)\,dx \qquad\text{(continuous)}$$

The "expected value" isn't necessarily a value $X$ can even take (E[die roll] = 3.5, and no face shows 3.5) — it's the long-run average over infinitely many draws.

## Variance — How Spread Out?

<DerivationSteps>
<DerivationStep number={1} title="Definition">
$$\text{Var}(X) = E[(X-E[X])^2]$$
The average squared distance from the mean. Squaring makes it always non-negative and penalizes big deviations more.
</DerivationStep>
<DerivationStep number={2} title="The computational shortcut">
$$\text{Var}(X) = E[X^2] - (E[X])^2$$
Same quantity, derived by expanding the square — often easier to compute since you only need two sums instead of first finding the mean and then re-scanning the data.
</DerivationStep>
<DerivationStep number={3} title="Standard deviation">
$$\sigma = \sqrt{\text{Var}(X)}$$
Back in the original units of $X$ (variance is in *squared* units) — this is the number that actually has an intuitive scale.
</DerivationStep>
</DerivationSteps>

## Covariance & Correlation

$$\text{Cov}(X,Y) = E[(X-E[X])(Y-E[Y])] \qquad\qquad r = \frac{\text{Cov}(X,Y)}{\sigma_X\sigma_Y}$$

Covariance's *sign* tells you the direction of the linear relationship (positive: move together; negative: move oppositely); its *magnitude* is hard to interpret because it depends on the scale of X and Y. Correlation $r \in [-1,1]$ fixes that by normalizing — this is exactly the covariance matrix from Module 4, just examined pairwise here instead of eigendecomposed.

<ExpectationCovarianceWidget />

<ConceptBox title="Common confusion — correlation is not causation, and it's only linear">
$r=0$ means no *linear* relationship — X and Y can still be tightly, deterministically related in a nonlinear way (e.g. $Y=X^2$ over a symmetric range gives $r\approx0$) and correlation would completely miss it. Always plot the scatter, don't just trust the number.
</ConceptBox>

## In Python (NumPy)

```python
import numpy as np

X = np.array([1, 2, 3, 4, 5])
Y = np.array([2, 4, 5, 4, 5])

print(X.mean(), X.var())          # E[X], Var(X)  (ddof=0 by default)
print(np.cov(X, Y, ddof=1))       # 2x2 covariance matrix
print(np.corrcoef(X, Y))          # 2x2 correlation matrix, diagonal = 1
```

## Practice

**Problem 1.** X takes value 0 with probability 0.5 and value 10 with probability 0.5. Find E[X] and Var(X).

**Solution:** $E[X]=0(0.5)+10(0.5)=5$. $\text{Var}(X) = 0.5(0-5)^2+0.5(10-5)^2 = 0.5(25)+0.5(25)=25$.

**Problem 2.** Cov(X,Y) = 12, Var(X)=16, Var(Y)=9. Find the correlation.

**Solution:** $r = 12/(\sqrt{16}\sqrt9) = 12/12 = 1$ — a perfect positive linear relationship.
