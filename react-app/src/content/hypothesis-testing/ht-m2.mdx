<Bridge>
**Why it matters.** A jury can make exactly two mistakes: convict the innocent, or acquit the guilty. They pull opposite ways — a jury reluctant to convict rarely jails the innocent but lets more guilty walk. Every hypothesis test faces the same two errors. Understanding, quantifying, and balancing them is the most consequential decision in any analysis.
</Bridge>

## Two Types of Error

A test ends in reject / fail-to-reject; reality is $H_0$ true / false. Crossing them gives four outcomes:

| | $H_0$ TRUE | $H_0$ FALSE |
|---|---|---|
| **Reject $H_0$** | Type I error (false positive) | Correct (power) |
| **Fail to reject** | Correct | Type II error (false negative) |

**Type I error ($\alpha$)** — reject a true $H_0$; a false alarm produced by sampling noise. Its probability is the significance level:

$$P(\text{Type I}) = P(\text{Reject } H_0 \mid H_0 \text{ true}) = \alpha$$

Drug trial: concluding the drug works when it doesn't. Court: convicting the innocent. QC: halting a good line. We control $\alpha$ directly, before data.

**Type II error ($\beta$)** — fail to reject a false $H_0$; a real effect goes undetected (small effect, small sample, or high variance):

$$P(\text{Type II}) = P(\text{Fail to reject } H_0 \mid H_0 \text{ false}) = \beta$$

Drug trial: missing a drug that helps. Court: acquitting the guilty.

**Power** = $1 - \beta$ = probability of correctly rejecting a false $H_0$. Researchers maximize it; low power is a smoke detector that only trips on big fires.

<ConceptBox title="What determines power?">
- **Sample size $n$** — larger $n$ narrows the sampling distribution; the most direct design lever.
- **Effect size $\delta$** — bigger true differences are easier to detect (a property of the world).
- **Significance level $\alpha$** — larger $\alpha$ widens the rejection region, raising power *and* false positives — the core trade-off.
- **Population variance $\sigma^2$** — less variability tightens the distribution.

80% power ($\beta = 0.20$) is a conventional minimum; medicine often targets 90%+. Power analysis before data fixes the $n$ needed.
</ConceptBox>

## The Significance Level α

$\alpha$ is the max Type I error rate you'll tolerate, set *before* data — setting or adjusting it after seeing results breaks the guarantee that the false-positive rate is controlled.

| $\alpha$ | When |
|---|---|
| **0.05** | Default in social/behavioral science; 1-in-20 false positive |
| **0.01** | High-cost false positives — drug approval, regulation; needs larger $n$ |
| **0.10** | Exploratory/pilot work, or when missing a real effect is costly |

Field-specific standards go far tighter: particle physics uses "5-sigma" ($\alpha \approx 2.87\times10^{-7}$); genomics uses $\sim5\times10^{-8}$ after Bonferroni. Choosing $\alpha$ is a policy decision — "beyond reasonable doubt" is a very small $\alpha$; missing a treatable disease shifts the balance the other way.

<ConceptBox title="The α–β trade-off (fixed n)">
For fixed $n$, $\alpha$ and $\beta$ move inversely: shrinking $\alpha$ (tighter rejection region) raises $\beta$ (lower power). The **only way to cut both at once** is a larger $n$, which shrinks the standard error and pulls the null and alternative distributions apart. That's why sample-size choice is inseparable from $\alpha$ and target power.
</ConceptBox>

## The p-value

The most misreported number in statistics — get it *precisely* right. The p-value is the probability of a test statistic at least as extreme as observed, *assuming $H_0$ is true*. Two-tailed:

$$p\text{-value} = P\!\left(|T| \geq |t_{\text{obs}}| \mid H_0 \text{ true}\right)$$

It measures compatibility with $H_0$: small p = the result would be very unlikely under $H_0$ = strong evidence against it; large p = entirely plausible under $H_0$ = no evidence against it.

**Decision rule:** $p \leq \alpha$ → reject (statistically significant); $p > \alpha$ → fail to reject.

<ConceptBox title="Three misconceptions about the p-value">
1. **"p = probability $H_0$ is true."** No — $H_0$ isn't a random variable, and p is computed *assuming* $H_0$ true. That statement needs a Bayesian prior, which classical testing doesn't use.
2. **"p = probability the result is due to chance."** No — p is how often *chance under $H_0$* would give a result this extreme, not a verdict on what caused this particular result.
3. **"p = 0.03 means a 3% chance of error if we reject."** No — the chance a rejected null is actually true (false discovery rate) also depends on how often $H_0$ is true across all tests, which p doesn't encode.
</ConceptBox>

The p-value is a continuous strength-of-evidence measure; the $\alpha$ threshold is a binary rule laid on top, chosen by convention, not read from the data.

## The Critical Value Method

Same decision, computed the other way: find the boundary statistic separating rejection from non-rejection — the critical value $z^*$ (or $t^*$).

$$\text{Two-tailed: reject if } |Z| > z^* = z_{\alpha/2} = \Phi^{-1}\!\left(1 - \tfrac{\alpha}{2}\right)$$
$$\text{Right-tailed: reject if } Z > z^* = z_\alpha = \Phi^{-1}(1 - \alpha)$$

Worth memorizing: two-tailed $z^* = 1.96$ at $\alpha=0.05$, $2.576$ at $\alpha=0.01$; one-tailed $z^* = 1.645$ at $\alpha=0.05$.

<ConceptBox title="The two methods always agree">
They're two readings of the same geometry:
$$|Z_{\text{obs}}| \geq z^* \iff p\text{-value} \leq \alpha$$
$z^*$ is *defined* as the value whose tail probability equals $\alpha$. Statistic equals $z^*$ → p equals $\alpha$; larger statistic → smaller p. They reach the same decision every time — use whichever is convenient.
</ConceptBox>

## Worked Example: Manufacturing QC

A machine fills bags to 500g, known $\sigma = 8$g. Sample $n = 36$, $\bar{x} = 497$g. Evidence the machine is off-target?

<DerivationSteps>
<DerivationStep number={1} title="Hypotheses">
$$H_0: \mu = 500 \quad \text{vs} \quad H_1: \mu \neq 500$$
Two-tailed — under- or over-filling is a problem, no prior direction.
</DerivationStep>
<DerivationStep number={2} title="Significance level">
$\alpha = 0.05$ — Type I (halting a good line) and Type II (missing a bad one) costs judged balanced.
</DerivationStep>
<DerivationStep number={3} title="Test statistic">
$$Z = \frac{497 - 500}{8 / \sqrt{36}} = \frac{-3}{1.333} = -2.25$$
The mean sits 2.25 standard errors below 500.
</DerivationStep>
<DerivationStep number={4} title="p-value method">
$$p = 2 \times P(Z < -2.25) = 2 \times 0.0122 = 0.0244$$
Doubled because two-tailed — the chance of landing ≥3g from 500 if calibrated.
</DerivationStep>
<DerivationStep number={5} title="Critical value method">
$$z^* = 1.96, \quad |Z_{\text{obs}}| = 2.25 > 1.96$$
In the rejection region — same decision.
</DerivationStep>
<DerivationStep number={6} title="Decide">
$p = 0.0244 < 0.05$ → **reject $H_0$**. At the 5% level, the mean fill weight is not 500g; recalibrate. Both methods agree, as they must.
</DerivationStep>
</DerivationSteps>

## Practice

New study app, historical $\mu_0 = 75$, $\sigma = 10$, $n = 25$, $\bar{x} = 79$. Test at $\alpha = 0.05$ both ways; the app can only *improve* scores.

**Hypotheses (right-tailed):** $H_0: \mu = 75$ vs $H_1: \mu > 75$.

**Statistic:** $Z = \dfrac{79 - 75}{10/\sqrt{25}} = \dfrac{4}{2} = 2.00$.

**p-value:** $P(Z > 2.00) = 1 - 0.9772 = 0.0228 < 0.05$ → **reject**.

**Critical value:** $z^* = z_{0.05} = 1.645$; $2.00 > 1.645$ → **reject**.

**Conclusion:** Both agree — at 5%, sufficient evidence the app raises scores above 75. (Statistical significance ≠ practical significance — weigh the 4-point gain on its real-world merit.)
