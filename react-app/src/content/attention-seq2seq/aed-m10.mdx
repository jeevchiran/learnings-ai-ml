## The context vector, defined

<PredictReveal
  prompt="Formally, c_i (the context vector for decoder step i) is a weighted sum of the encoder hidden states h_j. What must be true of the weights alpha_ij for c_i to count as a proper weighted average?"
  options={["They must all be equal to each other", "They must be non-negative and sum to 1 across j"]}
  correct={1}
>

$$c_i = \sum_{j=1}^{T_{src}} \alpha_{ij}\, h_j \qquad \text{where } \alpha_{ij} = \frac{\exp(e_{ij})}{\sum_{k=1}^{T_{src}} \exp(e_{ik})}$$

That denominator is softmax, applied across the source positions $j$ for a fixed decoder step $i$. It guarantees $\alpha_{ij} \geq 0$ and $\sum_j \alpha_{ij} = 1$ — exactly the two conditions that make $c_i$ a genuine weighted average of the $h_j$'s rather than an arbitrary combination. Nothing here has changed from Module 7; this is that same pipeline, written as one equation.

</PredictReveal>

## Three ways to compute the score $e_{ij}$

<DerivationSteps>
<DerivationStep number={1} title="Dot, general, and additive scoring">

Given the decoder's previous hidden state $s_{i-1}$ and an encoder state $h_j$, three standard score functions:

| Name | Formula | Learnable parameters |
|---|---|---|
| Dot (Luong) | $e_{ij} = s_{i-1}^\top h_j$ | none |
| General (Luong) | $e_{ij} = s_{i-1}^\top W_a\, h_j$ | $W_a$ |
| Additive (Bahdanau) | $e_{ij} = v_a^\top \tanh(W_a s_{i-1} + U_a h_j)$ | $v_a, W_a, U_a$ |

Dot is the cheapest — no extra parameters at all — but it requires $s_{i-1}$ and $h_j$ to have the same dimensionality, since it's a plain inner product. General relaxes that with a learned bilinear map. Additive is the most expressive, and the one Module 8's code used, at the cost of a small feedforward network run once per source position per decoder step.

</DerivationStep>
<DerivationStep number={2} title="Why scaled dot-product exists">

Take dot scoring with vectors of dimension $d$, whose components are roughly independent with mean 0 and variance 1. The dot product $s^\top h = \sum_{k=1}^d s_k h_k$ is a sum of $d$ roughly-independent terms, so its **variance grows linearly with $d$** — its typical magnitude grows like $\sqrt{d}$.

As $d$ gets large, raw dot-product scores spread out over a wide range, and softmax over a wide range saturates: one score dominates, the rest collapse toward zero, and the "soft" in soft attention stops meaning much. Dividing by $\sqrt{d}$ counteracts exactly this growth, keeping the scores at a roughly constant scale regardless of dimensionality:

$$e_{ij} = \frac{s_{i-1}^\top h_j}{\sqrt{d}}$$

This scaled dot-product is precisely the score function later adopted, unchanged, as the core of self-attention in the Transformer — the same variance argument, just applied there to a different pair of vectors.

</DerivationStep>
</DerivationSteps>

<ConceptBox title="TL;DR">
- $c_i = \sum_j \alpha_{ij} h_j$, with $\alpha_{ij} = \text{softmax}_j(e_{ij})$ — softmax is what guarantees $c_i$ is a genuine weighted average.
- Three standard score functions: **dot** (no extra parameters, needs matching dimensions), **general** (a learned bilinear map), **additive/Bahdanau** (a small feedforward network, most expressive).
- Dot-product scores have variance growing with dimension $d$, which can saturate softmax at high $d$ — **scaled dot-product** ($e_{ij} = s^\top h_j / \sqrt{d}$) corrects for this, and is exactly what the Transformer later reuses.
- The worked numeric example shows the full pipeline end to end: real hidden-state vectors, real dot products, real softmax weights, and the resulting context vector as their weighted sum.
</ConceptBox>
