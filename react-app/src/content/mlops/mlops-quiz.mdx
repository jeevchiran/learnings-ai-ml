## Streaming and recovery

<QuizCard question="Five standard Kafka consumers share a group subscribed to a topic with three partitions. At most how many can hold active partition assignments?" options={['3', '5', '15']} correct={0} explanation="In the standard consumer-group model, each partition has at most one assigned consumer per group. Extra consumers may remain idle." />

<QuizCard question="A sequential Kafka consumer has durably processed partition offset 41. Which offset should it commit next?" options={['40', '41', '42']} correct={2} explanation="The committed offset identifies the next position to resume from, so it advances beyond the completed record." />

<QuizCard question="A consumer crashes after persisting a prediction but before acknowledging the Pub/Sub message. What behavior should the application support?" options={['Redelivery with a duplicate-safe durable write', 'The message service rolling back the prediction database', 'A guarantee that the message can never reappear']} correct={0} explanation="There is a crash boundary between the database transaction and the acknowledgment. A unique logical event key prevents a replay from adding a second result." />

<QuizCard question="What is the difference between a Pub/Sub message ID and an application event ID?" options={['They must always contain identical strings', 'A message ID identifies a publication; an event ID can identify the same logical event across repeated publications', 'An event ID is the delivery acknowledgment ID']} correct={1} explanation="Republishing one logical event can create multiple service message IDs. Use a stable application key for business deduplication and the delivery ack ID for acknowledgment." />

<QuizCard question="Traffic arrives at 120 events/second and processing sustains 80 events/second. How much does the backlog grow in one minute?" options={['40 events', '7,200 events', '2,400 events']} correct={2} explanation="The excess is 120 - 80 = 40 events/second. Across 60 seconds, that is 2,400 additional events, assuming the rates stay constant." />
