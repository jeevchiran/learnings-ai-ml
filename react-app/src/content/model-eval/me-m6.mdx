## Scoring Features One at a Time

Filter methods score each feature by its relationship to the target — a statistic computed directly from the data, no model trained. Keep the top scorers (by count, fraction, or threshold), drop the rest. Because nothing gets fitted, they run on thousands of features as a first pass. Here are the five you'll reach for most, ordered by how much they assume. Toggle between the target-aware and target-blind ones:

## Variance Threshold

The simplest filter ignores the target entirely. A near-constant feature — say 998 of 1,000 rows share a value — carries almost no discriminative information. `VarianceThreshold` drops any feature below a variance cutoff.

```python
from sklearn.feature_selection import VarianceThreshold
import numpy as np

X = np.array([[0, 2, 0.1], [0, 1, 0.2], [1, 4, 0.1], [0, 3, 0.3], [0, 2, 0.1]])  # col 0 ≈ constant

selector = VarianceThreshold(threshold=0.05)
X_reduced = selector.fit_transform(X)
print(selector.get_support())    # [False  True  True] -- column 0 dropped
```

The caveat is in the name: it looks at variance only, never the target. A binary flag that is 1 for exactly one fraud case has near-zero variance yet may be the case you most need. Use it to drop obviously dead columns, not to judge relevance.

## Correlation-Based Filtering

For a numeric feature and numeric/binary target, Pearson correlation measures *linear* relationship strength:

$$r = \frac{\sum (x_i - \bar x)(y_i - \bar y)}{\sqrt{\sum(x_i-\bar x)^2}\sqrt{\sum(y_i - \bar y)^2}}$$

$r$ compares how $x$ and $y$ move together (covariance) against how much each moves alone — always in $[-1, 1]$, extremes = strong linear link, near 0 = little. Pointed at *feature pairs*, it also catches redundancy: two features near $\pm1$ carry the same information, so drop one.

```python
import pandas as pd

df = pd.DataFrame({
    "sqft": [850, 1200, 1500, 1800, 2200, 2600], "bedrooms": [2, 2, 3, 3, 4, 4],
    "n_windows": [8, 11, 14, 17, 21, 25], "price": [180, 240, 300, 355, 430, 500],
})
print(df.corr()["price"].drop("price").sort_values(ascending=False))   # sqft ~0.999, n_windows ~0.996
print(df[["sqft", "bedrooms", "n_windows"]].corr())                    # sqft & n_windows ~0.998 → redundant
```

Sharp limit: Pearson detects only *linear* relationships. A strong U-shaped feature can have $r \approx 0$ and get discarded silently.

## Chi-Square Test

For a categorical feature and categorical target, chi-square tests whether the two are independent — if they were, cell counts should match the marginals; a large statistic means the feature carries information. `chi2` requires non-negative values (counts, one-hot, or binned numerics — not standardized columns).

```python
from sklearn.feature_selection import SelectKBest, chi2
from sklearn.preprocessing import OneHotEncoder
import numpy as np

X_cat = np.array([["red","small"],["blue","large"],["red","large"],["green","small"],["blue","small"],["red","large"]])
y = np.array([1, 0, 1, 0, 0, 1])

X_enc = OneHotEncoder(sparse_output=False).fit_transform(X_cat)
selector = SelectKBest(chi2, k=2).fit(X_enc, y)
print(selector.scores_.round(3))    # chi-square per one-hot column
print(selector.get_support())       # top-2 kept
```

## ANOVA F-Test

For a numeric feature and categorical target, the F-test asks whether the feature's mean differs across classes — same mean everywhere = unhelpful; means far apart relative to within-class spread = discriminative. `f_classif` computes it per feature.

```python
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.datasets import load_iris

X, y = load_iris(return_X_y=True)
selector = SelectKBest(f_classif, k=2).fit(X, y)
print(selector.scores_.round(2))    # F-statistic per feature
```

Like correlation, it's about means and variances — class separation *on average*, not general shape differences.

## Mutual Information

Instead of testing for a specific relationship shape, MI asks a model-free question from information theory: *how much does knowing this feature reduce uncertainty about the target?* High if it narrows the target a lot, ≈0 if it tells you nothing. Crucially it captures *any* dependency — a U-shaped or periodic feature that correlation scores near 0 can register high MI.

```python
from sklearn.feature_selection import mutual_info_classif, SelectKBest
from sklearn.datasets import load_iris

X, y = load_iris(return_X_y=True)
print(mutual_info_classif(X, y, random_state=42).round(3))    # MI per feature
selector = SelectKBest(mutual_info_classif, k=2).fit(X, y)
```

The generality is also its weakness: MI is estimated from finite samples (a k-NN estimator), getting noisier as data shrinks or features grow. And there's no standard p-value — you compare relative scores, you don't test a hypothesis.

## Comparing the Five

| Method | Feature type | Target type | Nonlinear? | Fast? |
|---|---|---|---|---|
| Variance Threshold | Any | Ignored | N/A | Extremely fast |
| Pearson correlation | Numeric | Numeric/binary | No — linear only | Fast |
| Chi-square | Categorical/counts | Categorical | Yes (independence) | Fast |
| ANOVA F-test | Numeric | Categorical | No — means only | Fast |
| Mutual information | Any | Any | Yes — any dependency | Slower, noisier |

<ConceptBox title="Filters miss features that only matter together">
Every method scores one feature at a time — what makes filters fast makes them blind to *interactions*. In XOR, $x_1$ and $x_2$ are each individually uncorrelated with the target (and near-zero MI alone), but the target is exactly $x_1 \oplus x_2$ — perfectly determined by the pair. Every filter ranks both low and may drop both. This is structural to the whole family: "score each feature independently" and "detect a two-feature interaction" are contradictory. Closing the gap needs a real model evaluating subsets — wrapper methods, next.
</ConceptBox>

## Practice

#### Problem 1: Picking the Right Filter
(a) continuous gene expression → 4 disease subtypes, (b) one-hot survey answers → yes/no purchase, (c) sensor readings with a suspected U-shaped link to failure.

**Solution:** (a) ANOVA F-test — numeric features, categorical target, mean differs across subtypes. (b) Chi-square — both categorical, one-hot is non-negative. (c) Mutual information — a U-shape is non-monotonic, so correlation and the F-test score it near zero; MI is the one method here built to catch that shape.

#### Problem 2: Why the Interaction Gap Matters
Binary `a`, `b`, target = 1 exactly when `a != b` (XOR). What do correlation and single-feature MI report, and what does it reveal?

**Solution:** Against each feature alone, both are uncorrelated with the target — for fixed `a`, the target is 1 half the time as `b` varies, so no single-feature signal; both scores near zero, both may be dropped. Yet the pair is perfectly predictive. Filters evaluate one feature at a time and structurally can't notice that two individually-useless features are jointly informative — the gap wrapper methods close.
