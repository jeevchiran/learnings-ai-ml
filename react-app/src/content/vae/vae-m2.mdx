</ConceptBox>

## The Latent Variable Generative Story

We model data generation as a two-step hierarchical probabilistic process:

1. Sample a latent representation $z$ from a simple prior distribution:
   $$z \sim p(z) = \mathcal{N}(0, I)$$
2. Generate an observation $x$ from a conditional likelihood distribution parameterized by a neural network with weights $\theta$:
   $$x \sim p_\theta(x|z)$$

```
     p(z) = 𝒩(0, I)
         │
         ▼  Sample latent code z
     ┌───────┐
     │   z   │
     └───────┘
         │
         ▼  Decoder Neural Network p_θ(x|z)
     ┌───────┐
     │   x   │  Generated image / sample
     └───────┘
```

The joint distribution over observed data $x$ and latent code $z$ is:

$$p_\theta(x, z) = p_\theta(x|z) p(z)$$

## The Marginal Evidence: Intractable High-Dimensional Integral

To fit the model parameters $\theta$ via Maximum Likelihood Estimation (MLE), we want to maximize the marginal log-likelihood (also called the **evidence**) across all training points:

$$\log p_\theta(x) = \log \int p_\theta(x|z) p(z) \, dz$$

In high-dimensional latent spaces, the vast majority of randomly drawn vectors $z \sim \mathcal{N}(0, I)$ correspond to empty space that has almost zero probability of generating a specific target image $x$. 

To get an accurate Monte Carlo average:

$$\int p_\theta(x|z) p(z) \, dz \approx \frac{1}{N} \sum_{i=1}^N p_\theta(x|z^{(i)})$$

we would need $N \to \infty$ samples because almost every term in the sum is practically zero.

</PredictReveal>

## The Intractable True Posterior $p_\theta(z|x)$

By Bayes' theorem, the true posterior distribution over latent variables given an observation $x$ is:

$$p_\theta(z|x) = \frac{p_\theta(x|z) p(z)}{p_\theta(x)} = \frac{p_\theta(x|z) p(z)}{\int p_\theta(x|z') p(z') \, dz'}$$

Notice that the denominator is the exact same intractable marginal likelihood $p_\theta(x)$! 

Because we cannot evaluate $p_\theta(x)$, we **cannot evaluate or sample from the true posterior $p_\theta(z|x)$**.

## The Variational Inference Approach

Since we cannot compute the true posterior $p_\theta(z|x)$, **Variational Inference** introduces a tractable, parameterized family of distributions $q_\phi(z|x)$ (known as the **recognition model** or **probabilistic encoder**) to approximate it.

The encoder $q_\phi(z|x)$ is trained to produce distributions that match the true posterior as closely as possible by minimizing their Kullback-Leibler (KL) divergence:

$$D_{KL}\big(q_\phi(z|x) \,\|\, p_\theta(z|x)\big) = \int q_\phi(z|x) \log \frac{q_\phi(z|x)}{p_\theta(z|x)} \, dz$$

```
   Target: True posterior p_θ(z|x)  (Intractable, complex shape)
                     ▲
                     │  Minimize KL divergence
                     ▼
   Approximation: q_ϕ(z|x) = 𝒩(μ_ϕ(x), Σ_ϕ(x))  (Tractable Gaussian)
```

In the next module, we derive the exact objective function that allows us to minimize this divergence without ever calculating the intractable $p_\theta(z|x)$!
