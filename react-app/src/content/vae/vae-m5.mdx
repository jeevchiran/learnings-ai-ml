# Module 5: The Reparameterization Trick

<ConceptBox title="The Core Engineering Breakthrough">
The reparameterization trick makes backpropagation through stochastic latent layers possible. By expressing the random variable $z \sim \mathcal{N}(\mu, \sigma^2)$ as a deterministic function with an external noise input:

$$z = g_\phi(x, \epsilon) = \mu + \sigma \odot \epsilon, \qquad \text{where } \epsilon \sim \mathcal{N}(0, I)$$

gradients $\nabla_\phi \mathbb{E}_{q_\phi(z|x)}[f(z)]$ can flow smoothly through $\mu$ and $\sigma$ into the encoder parameters $\phi$.
</ConceptBox>

<Bridge>
Module 4 derived the analytical KL loss. However, to evaluate and backpropagate through the reconstruction loss $\mathbb{E}_{q_\phi(z|x)}[\log p_\theta(x|z)]$, the model must sample a latent vector $z$. This module solves the fundamental problem of backpropagating through random sampling.
</Bridge>

## The Problem: Stochastic Bottleneck

Suppose we implement sampling directly:

```python
# Non-differentiable direct sampling
z = torch.normal(mean=mu, std=sigma) # ❌ Breaks computational graph!
```

During the forward pass, this works fine. But during backpropagation, autograd needs to compute:

$$\frac{\partial \mathcal{L}_{\text{recon}}}{\partial \phi} = \frac{\partial \mathcal{L}_{\text{recon}}}{\partial z} \cdot \frac{\partial z}{\partial \phi}$$

What is $\frac{\partial z}{\partial \mu}$ when $z$ is drawn from a random number generator? **It is undefined!** The random sampling operation is a non-differentiable stochastic node that severs the gradient path.

```
       Non-Differentiable Graph:
       
       x ──► [ Encoder ϕ ] ──► (μ, σ²) ──► [ Random Sample z ] ──► [ Decoder θ ] ──► x̂
                                                │
                                    ❌ Gradient cannot cross here
```

## The Score-Function Estimator Alternative (and Why It Fails)

One classical alternative is the **REINFORCE / Score-Function estimator**:

$$\nabla_\phi \mathbb{E}_{q_\phi(z|x)}[f(z)] = \mathbb{E}_{q_\phi(z|x)}\big[ f(z) \nabla_\phi \log q_\phi(z|x) \big]$$

While mathematically unbiased, the variance of this estimator is **extremely high**. In deep neural networks, REINFORCE gradients are so noisy that training a VAE takes millions of iterations or fails to converge entirely.

## The Reparameterization Solution

The reparameterization trick isolates the stochasticity into an **independent, parameter-free noise variable** $\epsilon \sim \mathcal{N}(0, I)$:

$$z = \mu(x) + \sigma(x) \odot \epsilon$$

```
       Reparameterized Differentiable Graph:
       
                 ε ~ 𝒩(0, I)  (Independent noise)
                     │
                     ▼
       x ──► [ Encoder ϕ ] ──► (μ, σ) ──► [ z = μ + σ ⊙ ε ] ──► [ Decoder θ ] ──► x̂
                                                 ▲
                                                 │
                                 ✓ Differentiable deterministic node
```

Now, $z$ is a completely deterministic, differentiable function of $\mu$ and $\sigma$:

$$\frac{\partial z}{\partial \mu} = 1, \qquad \frac{\partial z}{\partial \sigma} = \epsilon$$

Since $\sigma = \exp(0.5 \times \text{logvar})$, the derivative with respect to `logvar` is:

$$\frac{\partial z}{\partial \text{logvar}} = \frac{\partial z}{\partial \sigma} \cdot \frac{\partial \sigma}{\partial \text{logvar}} = \epsilon \cdot \left(0.5 \cdot \exp(0.5 \times \text{logvar})\right) = 0.5 \cdot \sigma \cdot \epsilon$$

## PyTorch Implementation

In PyTorch, the reparameterization trick is implemented in just three lines:

```python
def reparameterize(mu, logvar):
    """
    Reparameterization trick: sample eps ~ N(0, I), return z = mu + std * eps
    """
    std = torch.exp(0.5 * logvar) # sigma = sqrt(exp(logvar))
    eps = torch.randn_like(std)    # sample noise with same shape and device
    return mu + eps * std          # pathwise differentiable latent code
```
