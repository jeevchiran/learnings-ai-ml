# Module 3: The Evidence Lower Bound (ELBO) Derivation

<ConceptBox title="The Core Equation of Variational Inference">
We cannot directly maximize the marginal data log-likelihood $\log p_\theta(x)$ because it involves an intractable integral. Instead, we maximize a tractable surrogate called the **Evidence Lower Bound (ELBO)**, which serves as a rigorous lower bound on $\log p_\theta(x)$:

$$\log p_\theta(x) \ge \text{ELBO}(\theta, \phi; x) = \mathbb{E}_{q_\phi(z|x)}\big[\log p_\theta(x|z)\big] - D_{KL}\big(q_\phi(z|x) \,\|\, p(z)\big)$$
</ConceptBox>

<Bridge>
Module 2 showed why the true posterior $p_\theta(z|x)$ cannot be evaluated. This module walks through the complete mathematical derivation that converts an impossible optimization problem into a tractable, differentiable neural network loss function.
</Bridge>

## Step-by-Step Mathematical Derivation

We start from the definition of the KL divergence between our approximate posterior $q_\phi(z|x)$ and the true posterior $p_\theta(z|x)$:

<DerivationSteps>
  <DerivationStep step={1} title="Definition of KL Divergence">
    By definition of the Kullback-Leibler divergence:
    $$D_{KL}\big(q_\phi(z|x) \,\|\, p_\theta(z|x)\big) = \int q_\phi(z|x) \log \frac{q_\phi(z|x)}{p_\theta(z|x)} \, dz = \mathbb{E}_{q_\phi(z|x)}\left[ \log \frac{q_\phi(z|x)}{p_\theta(z|x)} \right]$$
  </DerivationStep>

  <DerivationStep step={2} title="Apply Bayes' Rule to True Posterior">
    Substitute $p_\theta(z|x) = \frac{p_\theta(x, z)}{p_\theta(x)}$:
    $$D_{KL}\big(q_\phi(z|x) \,\|\, p_\theta(z|x)\big) = \mathbb{E}_{q_\phi(z|x)}\left[ \log \frac{q_\phi(z|x) \cdot p_\theta(x)}{p_\theta(x, z)} \right]$$
  </DerivationStep>

  <DerivationStep step={3} title="Split the Logarithm">
    Expand the logarithm into separate additive terms:
    $$D_{KL}\big(q_\phi(z|x) \,\|\, p_\theta(z|x)\big) = \mathbb{E}_{q_\phi(z|x)}\left[ \log q_\phi(z|x) - \log p_\theta(x, z) + \log p_\theta(x) \right]$$
  </DerivationStep>

  <DerivationStep step={4} title="Factor Out Evidence log p(x)">
    Since $\log p_\theta(x)$ has no dependence on the latent variable $z$, its expectation with respect to $q_\phi(z|x)$ is simply itself:
    $$D_{KL}\big(q_\phi(z|x) \,\|\, p_\theta(z|x)\big) = \mathbb{E}_{q_\phi(z|x)}\left[ \log q_\phi(z|x) - \log p_\theta(x, z) \right] + \log p_\theta(x)$$
  </DerivationStep>

  <DerivationStep step={5} title="Rearrange for Evidence log p(x)">
    Isolating $\log p_\theta(x)$ on the left-hand side yields:
    $$\log p_\theta(x) = \mathbb{E}_{q_\phi(z|x)}\left[ \log p_\theta(x, z) - \log q_\phi(z|x) \right] + D_{KL}\big(q_\phi(z|x) \,\|\, p_\theta(z|x)\big)$$
    $$\log p_\theta(x) = \text{ELBO}(\theta, \phi; x) + D_{KL}\big(q_\phi(z|x) \,\|\, p_\theta(z|x)\big)$$
  </DerivationStep>
</DerivationSteps>

## Why is it called a "Lower Bound"?

Because KL divergence is strictly non-negative ($D_{KL} \ge 0$), we have:

$$\log p_\theta(x) \ge \text{ELBO}(\theta, \phi; x)$$

with equality if and only if $q_\phi(z|x) = p_\theta(z|x)$ almost everywhere.

```
 Total Log-Evidence: log p_θ(x)
 ┌───────────────────────────────────────────────┬───────────────────────────┐
 │               ELBO(θ, ϕ; x)                   │  D_KL(q_ϕ(z|x) || p_θ(z|x))│
 │           (Maximized via SGD)                 │    (Approximation Gap)    │
 └───────────────────────────────────────────────┴───────────────────────────┘
 ▲                                               ▲
 0                                             Bound becomes exact when gap → 0
```

Because $\log p_\theta(x)$ does not depend on $\phi$ at all, maximizing $\text{ELBO}(\theta, \phi; x)$ with respect to $\phi$ is mathematically identical to **minimizing the KL divergence to the true posterior**:

$$\arg\max_\phi \text{ELBO}(\theta, \phi; x) \equiv \arg\min_\phi D_{KL}\big(q_\phi(z|x) \,\|\, p_\theta(z|x)\big)$$

This resolves the intractability problem: we can fit the recognition model $q_\phi(z|x)$ to the unknown true posterior without ever computing $p_\theta(z|x)$ directly!

</PredictReveal>

## Decomposing the ELBO: Two Competing Forces

By substituting $p_\theta(x, z) = p_\theta(x|z) p(z)$ into the ELBO definition, we obtain the standard two-term VAE objective:

$$\text{ELBO}(\theta, \phi; x) = \mathbb{E}_{q_\phi(z|x)}\left[ \log \frac{p_\theta(x|z) p(z)}{q_\phi(z|x)} \right]$$

$$\text{ELBO}(\theta, \phi; x) = \underbrace{\mathbb{E}_{q_\phi(z|x)}\big[\log p_\theta(x|z)\big]}_{\text{Reconstruction Log-Likelihood}} - \underbrace{D_{KL}\big(q_\phi(z|x) \,\|\, p(z)\big)}_{\text{Latent Prior Regularizer}}$$

The training loss minimized by gradient descent is the negative ELBO:

$$\mathcal{L}_{\text{VAE}}(\theta, \phi; x) = -\text{ELBO}(\theta, \phi; x) = \mathcal{L}_{\text{recon}}(x, \hat{x}) + D_{KL}\big(q_\phi(z|x) \,\|\, p(z)\big)$$

| Term | Role in VAE | What it rewards |
|---|---|---|
| **Reconstruction Likelihood** | Decoder quality | Sharp, accurate reconstruction of $x$ from sampled latents $z \sim q_\phi(z|x)$. |
| **KL Divergence to Prior** | Latent space regularity | Prevents overfitting by pulling $q_\phi(z|x)$ toward the standard normal prior $\mathcal{N}(0, I)$. |
