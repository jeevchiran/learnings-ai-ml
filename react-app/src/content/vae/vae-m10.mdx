## The Conditional VAE (CVAE)

In a CVAE (Sohn et al., NeurIPS 2015), both the encoder and decoder are conditioned on an auxiliary label $y$ (represented as a one-hot vector or embedding):

- **Encoder**: $q_\phi(z|x, y) = \mathcal{N}(\mu(x, y), \text{diag}(\sigma^2(x, y)))$
- **Decoder**: $p_\theta(x|z, y)$
- **Prior**: $p(z|y) = \mathcal{N}(0, I)$ (assumed independent of class or learned per class)

```
        Training:                           Targeted Generation:
        
   x ──┐                                         y (e.g. "Digit 7")
       ├─► [ Encoder ϕ ] ──► z                       │
   y ──┘                     │                       ▼
                             ▼             z ~ 𝒩(0, I) ──► [ Decoder θ ] ──► x̂ (Generated 7)
   y ───────────────► [ Decoder θ ] ──► x̂
```

The CVAE ELBO objective is:

$$\text{ELBO}_{\text{CVAE}} = \mathbb{E}_{q_\phi(z|x, y)}\big[ \log p_\theta(x|z, y) \big] - D_{KL}\big( q_\phi(z|x, y) \,\|\, p(z|y) \big)$$

### What Does the Latent Code $z$ Capture in a CVAE?

In a CVAE, the class identity is provided by $y$. Therefore, the latent variable $z$ no longer needs to encode *which* digit it is. Instead, $z$ learns only the **intra-class style and variation** (e.g. stroke thickness, tilt, slant, curvature).

## Discrete Latents: Vector Quantized VAE (VQ-VAE)

Standard VAEs use continuous Gaussian distributions. However, language, reasoning, and conceptual abstractions are naturally **discrete**.

**VQ-VAE** (van den Oord et al., NeurIPS 2017) passes the encoder output $z_e(x)$ through a learned discrete codebook $e \in \mathbb{R}^{K \times D}$:

$$z_q(x) = e_k \quad \text{where} \quad k = \arg\min_j \|z_e(x) - e_j\|_2$$

```
   Image x ──► Encoder ──► Continuous z_e(x)
                                 │
                                 ▼  Vector Quantization (Nearest Codebook Entry)
                           Discrete z_q(x) = e_k
                                 │
                                 ▼  Straight-Through Estimator (STE)
                           Decoder ──► x̂
```

Because discrete codebooks completely eliminate the Gaussian KL term, **VQ-VAEs never suffer from posterior collapse or Gaussian blurriness**. They are the foundation of modern Latent Diffusion Models (LDMs).

## Generative Model Family Comparison

| Model Family | Training Objective | Latent Space | Sampling Speed | Sample Quality / Fidelity | Mode Coverage / Stability |
|---|---|---|---|---|---|
| **VAE** | Likelihood-based (ELBO) | Continuous Gaussian / Smooth | Instant (1 forward pass) | Moderate (can be slightly blurry due to pixel MSE/BCE) | Excellent (stable, no mode collapse) |
| **GAN** | Adversarial Minimax Game | Continuous Noise | Instant (1 forward pass) | High (crisp, sharp textures) | Poor / Fragile (mode collapse, training instability) |
| **Normalizing Flows** | Exact Log-Likelihood $\log p(x)$ | Invertible Bijective Map | Instant | Moderate to High | High (exact density, but huge memory footprint) |
| **Diffusion Models** | Denoising Score Matching | Multi-step Gaussian Markov Chain | Slow (requires 20–50 iterative denoising steps) | State of the art | Excellent (stable, outstanding diversity) |
