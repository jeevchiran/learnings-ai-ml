# Module 10: β-VAE & Disentangled Representations

<ConceptBox title="The Disentanglement Objective">
The goal of a **disentangled representation** is to make separate latent coordinates control separate, interpretable factors, such as rotation or stroke thickness. **$\beta$-VAE** changes the pressure to compress information in the latent code. It can help toward this goal, but does not guarantee it.
</ConceptBox>

## The $\beta$-VAE Formulation

Introduced by Higgins et al. (ICLR 2017), $\beta$-VAE modifies the standard ELBO objective by introducing a hyperparameter $\beta > 0$ weighting the KL divergence term:

$$\mathcal{L}_{\beta\text{-VAE}}(\theta, \phi; x) = \mathbb{E}_{q_\phi(z|x)}\big[\log p_\theta(x|z)\big] - \beta \, D_{KL}\big(q_\phi(z|x) \,\|\, p(z)\big)$$

- When $\beta = 1$: Standard VAE (exact ELBO).
- When $\beta > 1$: Stronger information bottleneck, encouraging statistical independence and axis alignment.
- When $\beta < 1$: Weaker regularization, prioritizing sharp reconstructions at the expense of latent structure.

## Why Can a Larger $\beta$ Encourage Disentanglement?

The standard prior $p(z) = \mathcal{N}(0, I) = \prod_{j=1}^d \mathcal{N}(z_j; 0, 1)$ is **factorized** (all dimensions are statistically independent).

A larger KL weight makes encoding detailed input-specific information more expensive. On some datasets this encourages a simpler representation in which individual coordinates track useful factors. It does **not** force recovery of the true factors or guarantee alignment with individual axes. A diagonal Gaussian prior alone cannot identify a unique semantic coordinate system. See [Locatello et al. on the assumptions needed for disentanglement](https://arxiv.org/abs/1811.12359).

For example, suppose one latent coordinate changes a digit's thickness while another changes its slant. That is useful disentanglement. If both coordinates change both properties, the representation is entangled. Inspect the decoded changes rather than assuming that increasing beta achieved the desired result.

## The Hazard of $\beta \gg 1$: Posterior Collapse

When $\beta$ is excessively large, minimizing the KL divergence dominates the entire optimization. The easiest way for gradient descent to reduce loss is to set $\mu = 0$ and $\sigma^2 = 1$ everywhere.

If $q_\phi(z|x) = p(z)$ for every input, the sampled code carries no information about which input produced it. This is **posterior collapse**. A decoder trained to return a point estimate with squared-error loss may fall back toward a mean image. A powerful probabilistic decoder can instead model an unconditional distribution; a blurry mean image is not the definition of collapse.

</PredictReveal>

## Strategies That Can Reduce Posterior Collapse

1. **KL Annealing / Warm-up**: Start training with $\beta = 0$, gradually increasing $\beta \to 1$ or $\beta_{\text{target}}$ over the first $N$ epochs.
2. **Free Bits / Minimum KL Constraint**: Replace $D_{KL}$ with $\max(\tau, D_{KL})$, giving each dimension a budget of $\tau$ bits for free before applying regularization.
3. **Controlled Capacity Increase ($C$-VAE)**: Gradually increase a target capacity $C$: $\mathcal{L} = \mathcal{L}_{\text{recon}} - \gamma |D_{KL} - C|$.

<ConceptBox title="TL;DR">
- **$\beta$-VAE** simply weights the KL term: $\mathcal{L} = \text{reconstruction} - \beta \, D_{KL}$. $\beta = 1$ is the ordinary ELBO.
- $\beta > 1$ strengthens the KL penalty. It can encourage useful **disentanglement**, but neither independent semantic factors nor axis alignment is guaranteed.
- The cost is reconstruction sharpness, so $\beta$ is a **dial between disentanglement and fidelity**, not a free improvement.
- An overwhelming KL penalty can encourage **posterior collapse**: the code carries little or no input-specific information. **KL annealing** and **free bits** can help, but do not guarantee prevention.
</ConceptBox>
