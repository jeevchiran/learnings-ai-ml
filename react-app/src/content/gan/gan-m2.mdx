# Module 2: The Minimax Game — Generator & Discriminator

<Bridge>
Module 1 established that a GAN's only training signal comes from a discriminator's judgment. This module writes that judgment down as a single equation, and asks what it means for both networks to optimize it at once.
</Bridge>

## The value function

Both networks share one scalar objective, the **minimax value function**:

$$\min_G \max_D V(D, G) = \mathbb{E}_{x \sim p_{data}}[\log D(x)] + \mathbb{E}_{z \sim p_z}[\log(1 - D(G(z)))]$$

D outputs a probability that its input is real. It is trained to **maximize** V: push $D(x)$ toward 1 for real data and $D(G(z))$ toward 0 for generated data. G is trained to **minimize** the same V: push $D(G(z))$ toward 1, i.e. make the discriminator believe its output is real.

At the Nash equilibrium of this game, $p_g = p_{data}$: the generator's distribution exactly matches the real data distribution. At that point there is no feature left that distinguishes a real sample from a generated one, so the best D can do anywhere is guess — $D(x) = \tfrac{1}{2}$ for every $x$. A discriminator stuck at 50% accuracy is not a training failure here; for a perfectly-trained GAN, it is the goal.

## A saddle point, not a single minimum

<PredictReveal
  prompt="Ordinary supervised training finds a minimum of one loss function. GAN training alternates gradient ascent on D and gradient descent on G against the same V(D, G). What kind of point is the training actually looking for?"
  options={["A single global minimum of V, the same way a classifier finds a minimum of cross-entropy", "A saddle point of V — a maximum along D's direction and a minimum along G's direction, simultaneously"]}
  correct={1}
>

There is no single loss surface with one minimum here. $V(D,G)$ is maximized over D's parameters and minimized over G's parameters at the same time — the target is a **saddle point**, stable in one direction and unstable in the other. In practice this is approximated by alternating steps: hold G fixed and take a gradient step to improve D, then hold D fixed and take a gradient step to improve G, repeat. Nothing guarantees this alternation converges the way gradient descent on a single convex loss does — that instability is the subject of the next two modules.

</PredictReveal>

## Optional depth — where D(x) = 1/2 actually comes from

The claim above was asserted; it is worth seeing that it falls out of the value function in three lines. Nothing later in the track depends on having followed this.

Write the value function as integrals over $x$ rather than expectations, using $p_g$ for the distribution of $G(z)$:

$$V(D, G) = \int_x p_{data}(x) \log D(x) \, dx + \int_x p_g(x) \log(1 - D(x)) \, dx$$

For a **fixed** G, the discriminator can be optimised independently at each $x$ — nothing couples one input to another. So at a single point, writing $a = p_{data}(x)$, $b = p_g(x)$ and $y = D(x)$, we are maximising:

$$a \log y + b \log(1 - y)$$

Differentiate and set to zero:

$$\frac{a}{y} - \frac{b}{1-y} = 0 \quad \Longrightarrow \quad a(1-y) = by \quad \Longrightarrow \quad y = \frac{a}{a + b}$$

which is the optimal discriminator:

$$D^*(x) = \frac{p_{data}(x)}{p_{data}(x) + p_g(x)}$$

Now set $p_g = p_{data}$, the condition the generator is driving toward. Every $x$ gives $D^*(x) = \frac{p_{data}}{2p_{data}} = \tfrac{1}{2}$ — the equilibrium value, derived rather than assumed. The widget above plots exactly this formula.

Substituting $D^*$ back into $V$ gives $V = -\log 4 + 2 \cdot \text{JSD}(p_{data} \,\|\, p_g)$, where JSD is the Jensen-Shannon divergence. That identity is the reason Module 6 can say the original GAN loss "is" JS divergence in disguise — and it is what Module 6 then argues is the wrong thing to be minimising.

---

<ConceptBox title="TL;DR">
- Both networks share one value function $V(D,G) = \mathbb{E}[\log D(x)] + \mathbb{E}[\log(1-D(G(z)))]$: D maximizes it, G minimizes it.
- At the theoretical fixed point, $p_g = p_{data}$ and the optimal discriminator sits at $D(x) = \tfrac{1}{2}$ everywhere — it can no longer distinguish real from fake.
- Training alternates gradient steps on D and G against the shared objective, searching for a **saddle point**, not a minimum — which is why GAN training does not behave like ordinary supervised optimization.
</ConceptBox>
