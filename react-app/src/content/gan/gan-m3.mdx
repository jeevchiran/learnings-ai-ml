## Vanishing gradients from an early, confident D

G's half of the value function is $\log(1 - D(G(z)))$, minimized over G's parameters.

<PredictReveal
  prompt="Early in training, G produces obvious fakes, so D(G(z)) is close to 0 for almost every z. In that regime, how large is the gradient of log(1 - D(G(z))) with respect to G's parameters?"
  options={["Large — early mistakes give G its strongest learning signal", "Very small — the function is nearly flat exactly where G needs gradient most"]}
  correct={1}
>

Plot $\log(1-y)$ for $y$ near 0: the curve is nearly flat there. Its derivative with respect to $y$ is $\frac{-1}{1-y}$, which is close to $-1$ when $y \approx 0$ — small in magnitude, not the strong corrective push the intuition "G is failing badly, so it should learn fast" would suggest. A discriminator that gets good quickly (which is easy, since telling early garbage from real data is an easy classification problem) leaves G with almost no gradient to climb out of that garbage with.

</PredictReveal>

## The non-saturating fix

<PredictReveal
  prompt="Instead of minimizing log(1 - D(G(z))), Goodfellow et al.'s original paper proposes G maximize log(D(G(z))) instead — same fixed point, different early-training gradient. Which region of the curve does this rewrite move G's gradient into?"
  options={["The same flat region as before, just relabeled", "The steep region near D(G(z)) ≈ 0, where the new objective has its strongest gradient"]}
  correct={1}
>

$\log(y)$ near $y=0$ is steep — its derivative $\frac{1}{y}$ blows up as $y \to 0$. Maximizing $\log(D(G(z)))$ gives exactly the same direction of improvement as minimizing $\log(1-D(G(z)))$ — both push $D(G(z))$ toward 1 — but the **non-saturating** version supplies a large, useful gradient in precisely the regime where the original formulation goes flat. This is why almost every practical GAN implementation trains G against $-\log D(G(z))$ rather than the textbook minimax form.

</PredictReveal>

<Recall items={[
  { q: "What changes between the original minimax generator loss and the non-saturating generator loss, and what stays the same?", a: "Both push D(G(z)) toward 1, so they share the same fixed point and direction of improvement. What changes is the gradient magnitude early in training: log(D(G(z))) is steep near D(G(z)) ≈ 0, supplying a strong gradient exactly where log(1 - D(G(z))) was nearly flat." },
]} />

---

<ConceptBox title="TL;DR">
- G's original loss $\log(1-D(G(z)))$ is nearly flat when D(G(z)) ≈ 0 — exactly the regime a fresh, untrained generator starts in — so it supplies almost no gradient when G needs it most.
- The **non-saturating loss** has G maximize $\log(D(G(z)))$ instead. Same fixed point, same direction of improvement, but a steep, useful gradient in that same early regime.
- Nearly every practical GAN implementation trains G against the non-saturating form, not the textbook minimax objective from Module 2.
</ConceptBox>
